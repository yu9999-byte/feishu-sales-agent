## 2. 公开材料中的主要能力

- 通过表单、口述、会议和文档记录销售跟进。
- 将非结构化沟通转成需求、异议、共识和下一步。
- 检查信息完整度，识别商机停滞与风险。
- 自动形成任务、日报和周报。
- 根据客户历史生成拜访攻略和推进建议。
- 汇总目标、Commit、预测和 Gap，并下钻到商机证据。
- 从赢单与输单中提炼组织销售打法。

## 4. P0 等价范围

P0 的“参考竞品”只要求核心输入到行动闭环成立，不要求功能数量、视觉布局或商业成熟度相同。

```text
销售原话
-> 结构化理解
-> 用户确认
-> 客户/商机/跟进沉淀
-> 真实任务
```

## 6. 2026-09-20 本项目交互决策

竞品公开材料确认了填写时完整度检查、从下一步抽取任务、项目推进质检、报告与提醒等能力，
但没有证据证明其固定发送三张卡。本项目独立确定：机器人来源在原聊天用草案质检卡一次确认
跟进与本人待办，保存后发送结果任务卡；项目推进质检仅在新风险、关键变化或主动请求时
条件发送。跨角色推送、日报周报和提醒属于独立事件。完整取舍见
[跟进卡片决策问答](decisions/2026-09-20-followup-chat-cards.md)。
