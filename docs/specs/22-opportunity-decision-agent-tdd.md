## 1. 核心场景

| 场景 | 预期 |
| --- | --- |
| 多个本人进行中商机 | 按健康等级、风险分数、真实金额和稳定名称顺序返回 |
| 下一步逾期或已确认任务逾期 | 标记 `critical`，给出先核对并重新承诺的建议 |
| 14/30 天无可信跟进 | 生成中/高风险并引用最近跟进时间 |
| 无跟进或沟通时间缺失 | 分别显示无证据或时间缺失，不伪造最近联系日期 |
| 客户、进展、金额、下一步或时间缺失 | 生成对应缺口；金额缺失不虚构金额或概率 |
| 已赢单、已丢单、已关闭 | 从推进队列排除并计入排除数量 |
| 生命周期未知 | 保留在队列并提示人工确认，不从进展文本猜状态 |
| 普通任务标题包含商机名 | 只作为全局任务风险，不绑定具体商机 |
| Agent 成功动作含明确商机名和 `taskGuid` | 允许把该任务承诺绑定到商机并读取履约状态 |
| 部分来源分页或权限映射缺失 | 返回 `partial`/`unavailable` 和 warning，不补造事实 |
| 机器人业务查询或项目诊断 | 调用真实决策服务，输出最该推进对象、原因、下一步和证据 |
| 决策服务读取任务履约 | 使用 `readOnly=true`，不保存任务状态快照 |
| Web 未登录、无权限、跨租户 | 分别返回 401、403 或失败关闭，不读取越权数据 |
