# 任务历史与无任务承诺证据 SDD / TDD

状态：本地实现与验证完成（2026-10-20）；真实全量历史源及身份 UAT 待外部条件。需求 TASK-008、TASK-009。

2026-10-21 补验：观察账本回退路径复用可信历史的事件有效性校验。未来/越界/非法时间、无效完成证据、空或重复事件标识、同 GUID 同时刻冲突均使本批历史不可采信，缺失任务对应承诺保留 `unknown`，不计入完成或仍未完成统计。不得丢弃无效新事件后重新采用旧终态。正常观察证据仍仅标记 `agent_observations`。新增 17 项回归先 15 失败后全部通过，隔离 PostgreSQL/HTTP 5 项新回归通过；见[补验证据](../evidence/task-history-observations-20261021/verification.md)。

## 结果与边界

1. 完整任务历史必须由可信适配器提供租户、本人、精确 GUID 范围、覆盖起止时间、无缺口及分页结束证明。仅返回 `coverage=full` 不足以升级；越界/未来/无效时间、冲突事件、无效完成证据必须保守降级。现有飞书搜索及回执继续只代表观察账本，接入全量历史源仍待外部条件。
2. 对当前本人成功跟进动作中没有任务 GUID、且有明确下一步的承诺，提供独立凭证账本。默认采用本人明确确认并附凭证，状态为 `reported_fulfilled` / `reported_partial` / `retracted`。该状态不改变 `completionState`，不计入任务完成数或自动验证的完成率。
3. 人工凭证只证明本人作出该声明；链接内容未自动核验。缺少凭证仍待核实，不按标题、文本或任务缺席推断兑现。
4. 本地开发及隔离验证允许；不新增真实飞书消息、客户/商机/跟进/任务写入、权限或线上部署。

## 数据与接口

- GET `/api/platform/task-promises/:actionId/evidence?beforeRevision=...`：`task:read`，本人范围；返回当前记录、每页 20 条历史、下一游标。空账本 revision 为 0。
- POST 同路径：额外要求既有 `followup:create-own`，身份全部取可信 Session。请求为 requestId(UUID)、expectedRevision(0..2147483646)、state、note(2..500)、evidenceUrl。非撤回状态必须有 HTTPS 飞书文档/Wiki/Base/妙记凭证；禁凭证 URL 用户名/密码。链接仅存储和展示，不由服务端访问。
- 迁移 034：按租户/成功动作/序号的只追加记录；保留请求、预期修订、本人声明状态、说明、链接、操作人和服务端时间。锁定原动作，重新核对本人、成功跟进、有下一步、无任务，再核对修订。相同请求全部字段一致重放原事件；同键不同参数或过期修订返回 409，零追加。撤回只追加事件，不抹去历史。
- 原动作不属于本人、其他租户或无此动作返回 404；动作不满足无任务承诺条件返回 409。401/403/404/409/422/503 与所有响应 no-store；数据库错误脱敏，不回显内部连接信息。
- 不新增身份系统、权限类型或对外 OpenAPI。操作不会修改原始跟进、任务或承诺内容。

## 交互

任务页无任务承诺提供“核查凭证”入口，弹窗显示精确承诺、本人确认状态与凭证历史。使用现有 shadcn 控件。未加载成功或数据冲突时禁用提交；必填说明和凭证；提交中锁定。未知响应保留原请求并使用相同 requestId 重试，不重新生成请求。409 保留输入、丢弃旧请求并要求刷新；401/403/404 清除内容。关闭/切换承诺后忽略迟到响应。撤回需明确点击确认保存，不能仅切换选项就执行。
