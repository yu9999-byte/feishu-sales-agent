# Playbook 优化 Agent v1 — TDD

## 自动验收

1. 无可信答案立即创建待审核候选。
2. 同一租户、同一标准化问题只保留一条候选并递增次数。
3. 已回答问题前两次保持观察，第 3 次进入高频问题待审核。
4. 部分可用或完全不可用生成资料健康候选。
5. 同一来源版本变化生成复核候选。
6. 不同租户的数据与审核操作完全隔离。
7. 存储内容不含问题全文、答案、正文、摘录、客户、商机、跟进或任务数据。
8. 列表与审核都要求可信登录和 `playbook:review`。
9. `expectedUpdatedAt` 不一致时零写入并返回冲突。
10. “进入待编写”和“忽略”都生成不可变审核记录。
11. 观测失败不阻断正常知识问答，并产生脱敏失败审计。
12. 模块可由完整 Nest 应用装配并启动；不存在发布接口。

## 质量门

- 新增单元测试与 PostgreSQL 集成测试
- 全量 Vitest、Lint、类型检查、Agent/Web 构建
- 迁移连续执行两次保持幂等
- 隔离端口启动冒烟：主页、Playbook 页面、未登录 API
- Git diff whitespace 检查
