# 团队 Review Agent SDD

状态：`Automated Green / UI pending / 2026-09-30`

## 目标

为主管提供一个只读的团队当天复盘快照：把团队成员的个人日报聚合为成员状态、逾期任务、
跟进数量、商机数量、需要关注的成员和建议管理动作。它是管理视角的聚合 Agent，不替代
销售跟进 Agent，也不直接修改客户、商机、跟进或任务。

## 输入与权限

- 入口：`GET /api/platform/team-review?date=YYYY-MM-DD`。
- 必须通过当前 Web 会话认证，并具备 `review:read-team` 权限。
- 当前成员、租户、角色、租户时区来自服务端会话，不能由前端传入。
- `manager` 只读取本人和有效汇报关系中的递归下属；`executive`/`admin` 读取租户内有效成员。
- 已禁用成员、跨租户成员和无效汇报关系不进入结果。

## 聚合规则

1. 每个可见成员复用个人日报只读服务，使用该成员的飞书身份和同一租户时区。
2. 指标只做确定性求和：跟进、商机、未完成任务和逾期任务。
3. `unavailable` 或 `partial` 的成员会进入关注项，但不会被计入“有当天数据”的成员数。
4. 逾期任务产生高优先级关注；当天没有跟进或跟进没有下一步产生中优先级关注。
5. 来源不完整时整体返回 `partial`；所有成员都不可用时返回 `unavailable`；没有数据时返回 `empty`。
6. `managerActions` 只给出建议文本，不创建任务、不发送消息、不升级主管。

## 验收

- Red/Green：主管递归范围、高管全租户范围、禁用成员过滤、逾期风险、来源不可用和无效成员。
- 服务端 TypeScript、ESLint、Agent 构建和 Agent 单测必须通过。
- 真实 Web/飞书页面、主管账号和管理动作尚未验收，不能标记为 `UI Verified`。
