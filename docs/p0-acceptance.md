## 5. 明确不验收

以下能力不是 P0 缺陷或遗留项：

- 独立 Web 页面。
- CRM、企业数据库或其他 Base 的配置页面。
- 群聊、语音、图片、文档和会议输入。
- 飞书任务完成状态回收。
- 经营预测、团队管理和 Playbook。
- 计费、自助开通和应用市场发布。
