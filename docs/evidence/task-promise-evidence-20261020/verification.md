## 剩余验收

- 真实完整历史源必须提供可信身份、精确 GUID 与起止范围、无缺口及分页结束证明；目前没有适配器满足，完整历史仍未完成。
- 有效飞书身份下验收任务页和本人凭证；如要读凭证内容并自动核验，应另行定义可信读取及证据规则。
- 本次没有新增真实飞书消息、客户/商机/跟进/任务写入、权限、外网暴露或生产部署。原业务 runtime 的数据库故障未处理。
